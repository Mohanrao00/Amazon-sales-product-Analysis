# Amazon-sales-product-Analysis
Amazon product sales using Power Bi

Amazon Products Sales Analysis Dashboard

Project Overview

This project analyses Amazon product sales using Microsoft Power BI.

Tools Used

- Microsoft Power BI
- Power Query
- DAX

Dashboard Features

- YTD Sales
- QTD Sales
- YTD Products Sold
- YTD Reviews
- Monthly Sales Analysis
- Weekly Sales Analysis
- Product Category Analysis
- Top 5 Products by Sales
- Top 5 Products by Reviews

Objective

To analyse sales performance, identify top-performing products and understand product category trends.
